Privacy Policy

Last updated: October 25, 2026

YouTube Shorts Automation is a personal tool operated by Suresh Rana for YouTube channels he owns or manages. This policy covers the application's use of Google and YouTube user data.

Information accessed

  • Authorized channel information, including channel ID, name, description, and upload information available through the granted read-only permission.
  • OAuth access and refresh tokens needed to perform authorized YouTube API operations.
  • Videos and associated titles, descriptions, and publishing settings supplied for upload.

Purpose

This information is used to identify the correct channel, check uploads, and publish videos as authorized by the operator. The application does not request the user's Google account password.

Storage and security

OAuth credentials and tokens must be stored in protected secret storage, such as GitHub Actions Secrets. They must not be included in public repositories, website files, video descriptions, or public logs.

Channel identifiers and upload records may be retained for configuration, troubleshooting, and duplicate-upload prevention. Temporary media may be processed on cloud runners and retained as workflow artifacts.

Service providers and sharing

Google and YouTube receive authorized API requests and uploaded videos. GitHub may process credentials and media when running the automation.

Content-generation providers may receive research queries, scripts, or audio needed to create videos. OAuth credentials and private YouTube account data must not be sent to these providers.

Google user data is not sold, used for advertising, or used to train generalized AI or machine-learning models.

Google API Limited Use

The application's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

Retention and deletion

Tokens are retained only while the channel connection is needed. On disconnection, the operator must remove related tokens from secret storage and delete unneeded application records and artifacts.

You can revoke authorization through Google Account connections . Revocation prevents further authorized access but does not itself delete previously stored files or uploaded videos. Uploaded videos can be managed in YouTube Studio.

To request deletion of application-held data, contact the operator using the address below.
